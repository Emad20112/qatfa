# وثيقة مواصفات مكونات الشاشات بالتفصيل (Screen Specifications & UI/UX Breakdown) | منصة قطفة

---

## 1. المعايير الهندسية والجمالية لنظام التصميم (Design System Standards)

تم بناء تجربة واجهة المستخدم (UI/UX) في منصة **قطفة** لتجمع بين **الأصالة التراثية اليمنية**، و**التباين اللوني العالي لمقاومة وهج الشمس في الأسواق**، و**البساطة المتناهية التي تناسب كافة المستويات الثقافية والتقنية**:

### 1.1 لوحة الألوان المعتمدة (Color Palette)
- **الأخضر القاتمي الأساسي (`#1B5E20` - Qat Leaf):** يمثل أصالة نبتة القات والخضار الطبيعي للمزارع، ويُستخدم في الأشرطة العلوية والأزرار الرئيسية وشعارات التوثيق.
- **الأخضر النضر الحيوي (`#2E7D32` - Fresh Sprout):** لون عروض القطفة المتجددة وعلامات [متوفر الآن].
- **برتقالي العقيق اليماني (`#E65100` - Agate Accent):** لون الأزرار التفاعلية الحيوية، وشارات الأسعار البارزة، ونقرات الاتصال.
- **أخضر الواتساب المعتمد (`#25D366` - WhatsApp Green):** لزر التواصل الفوري عبر تطبيق WhatsApp.
- **رمادي الأسطح الهادئ (`#F4F6F8` - Surface Grey):** خلفية التطبيق لمنع إجهاد العين تحت الضوء الساطع.
- **أبيض ناصع نقي (`#FFFFFF` - Pure White):** خلفيات البطاقات والنوافذ المنبثقة لإبراز المحتوى.
- **أحمر التنبيه والنفاذ (`#D32F2F` - Sold Out Red):** لشارات [نفدت الكمية]، وأزرار الإبلاغ عن المحتوى المضلل.

### 1.2 التيبوجرافي ونظام الخطوط (Typography)
- **عائلة الخط:** **Cairo** كخط عربي أساسي، مدعوم بخط أرقام لاتيني هندسي واضح.
- **Headline 1 (22sp - Bold):** أسماء الأسواق وعناوين المتاجر الكبرى.
- **Headline 2 (18sp - Semi-Bold):** عناوين بطاقات القطفة اليومية.
- **Price Tag (20sp - Extra-Bold):** أرقام الأسعار بالريال اليمني (عالية التباين والوضوح).
- **Body Regular (14sp - Regular):** نصوص الوصف، وملاحظات المزارع، والتقييمات.
- **Caption / Timestamp (11sp - Medium):** مؤشرات التوقيت ("تم التحديث قبل 10 دقائق").

## 2. تفصيل مكونات الشاشات شاشة بشاشة (Screen-by-Screen Component Specs)

---

### 1. شاشة البداية والتهيئة السريعة (Splash & Fast Boot Screen)

#### الهدف من الشاشة:
فتح التطبيق في **أقل من 1.2 ثانية**، والتحقق من الذاكرة المحلية، وتوجيه المستخدم فوراً لموجز قطفات اليوم دون أي تأخير.

```
┌──────────────────────────────────────────────┐
│                                              │
│                                              │
│                   🌿                         │
│                 قـطـفـة                      │
│                  QATFA                       │
│      أكبر سوق إلكتروني للقات في اليمن        │
│                                              │
│                  •••••                       │
│        (تحميل فوري من الذاكرة المحلية)       │
│                                              │
└──────────────────────────────────────────────┘
```

#### المكونات والعناصر:
1. **الخلفية:** تدرج لوني عميق من الأخضر القاتمي الداكن (`#0D3813` إلى `#1B5E20`).
2. **الشعار:** أيقونة غصن قات منمنم مستوحى من النقوش اليمانية باللون الذهبي العقيقي مع كلمة "قطفة" بخط عربي كوفي حديث.
3. **مؤشر التحميل الهيكلي (Micro Loader):** وميض خفيف وسلس ينتهي خلال 800 ميلي ثانية.
4. **شريط الحالة (Status Bar):** شفاف مع أيقونات بيضاء واضحة.
5. **منطق الانتقال:** إذا تم تحديد المحافظة مسبقاً، ينتقل مباشرة إلى "الشاشة الرئيسية"، وإذا كانت المرة الأولى تظهر نافذة اختيار المدينة السريعة فوق الخلفية دون شاشات وسيطة.

### 2. الشاشة الرئيسية: موجز قطفات اليوم المتجددة (Home - Live Daily Drops Feed)

#### الهدف من الشاشة:
الشاشة المحورية الأولى للمشتري؛ تجمع كافة عروض القات والأسعار والمناطق وأسماء المقاوتية في مكان واحد منظم يغنيه تماماً عن تشتت مجموعات الواتساب والتليجرام.

```
┌──────────────────────────────────────────────┐
│ [📍 صنعاء - سوق علي محسن ▼]      [🔍] [🔔]   │  <- الشريط العلوي وتحديد السوق
├──────────────────────────────────────────────┤
│ (كل الأسواق) [خريطة السوق 🗺️] (المفضلة)     │  <- التبويبات الرئيسية
├──────────────────────────────────────────────┤
│ [الكل] [همداني] [شامي] [قعطبي] [عنسي] [رداعي]│  <- شريط رقاقات أنواع القات
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │
│ │ 🟢 متوفر الآن     ⏱️ تم التحديث قبل 8 د   │ │  <- شارة الحالة والتوقيت
│ │ ┌──────────────────────────────────────┐ │ │
│ │ │                                      │ │ │
│ │ │       [صورة حقيقية واضحة للقات]      │ │ │  <- صورة عريضة 16:9
│ │ │                                      │ │ │
│ │ └──────────────────────────────────────┘ │ │
│ │ شامي أبيض فاخر (قطفة الصباح الطازجة)    │ │  <- اسم الصنف والنوع
│ │ 🏪 مفرش العم صالح  🛡️ رقم موثق  ⭐ 4.9    │ │  <- بيانات المقاوتي والثقة
│ │ 📍 سوق علي محسن - مفرش رقم 14           │ │  <- الموقع الدقيق
│ │ 💰 12,000 ريال / حبة                    │ │  <- السعر الواضح البارز
│ │ ────────────────────────────────────── │ │
│ │ [ 💬 واتساب ]   [ 📞 اتصال ]   [ 🔗 ]  │ │  <- أزرار الإجراء السريع
│ └──────────────────────────────────────────┘ │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ 🔴 نفدت الكمية     ⏱️ نُشرت الساعة 12:10   │ │  <- عرض منتهي بحالة رمادية
│ │ ...                                      │ │
└──────────────────────────────────────────────┘
```

#### تفصيل مكونات الشاشة:

##### أ. شريط التطبيق العلوي (Top AppBar):
- **محدد الموقع الجغرافي (Location Selector):** زر عريض في أعلى اليمين يعرض: `[📍 صنعاء - سوق علي محسن ▼]`؛ النقر عليه يفتح قائمة منسدلة سريعة لاختيار محافظة أو سوق شعبي آخر.
- **أيقونة البحث السريع (Search Icon):** تفتح شريط البحث الفوري بالاسم أو الصنف.
- **أيقونة الإشعارات (Notification Bell):** جرس يحمل نقطة حمراء عند ورود إشعار بنزول قطفة جديدة من المتاجر المتابعة.

##### ب. شريط التبويبات ومحددات العرض (View Switcher):
- تبويب `[ عروض القطفات ]` (الوضع الافتراضي للقائمة المنظمة).
- تبويب `[ خريطة السوق 🗺️ ]` (التحويل الفوري لعرض مفارش السوق على الخريطة).
- تبويب `[ متابعاتي ]` (موجز مقاوتيتي المفضلين فقط).

##### ج. شريط رقاقات أنواع القات (Horizontal Qat Type Chips):
- شريط أفقي قابل للتمرير السلس يتضمن أصناف القات المتداولة في اليمن:
  `[ الكل ]` | `[ همداني ]` | `[ شامي ]` | `[ قعطبي ]` | `[ عنسي ]` | `[ رداعي ]` | `[ أرحبي ]` | `[ غيلي ]` | `[ يافعي ]`.
- النقر على أي نوع يُفلتر القائمة فوراً خلال 50 ميلي ثانية من الذاكرة المحلية دون إعادة تحميل الشاشة.

##### د. بطاقة القطفة اليومية (Daily Drop Card Component):
- **رأس البطاقة (Card Header):**
  - شارة خضراء في اليمين: `[ 🟢 متوفر الآن ]` أو شارة رمادية `[ 🔴 نفدت الكمية ]`.
  - شارة توقيت التحديث في اليسار: `⏱️ تم التحديث: منذ 8 دقائق` (تتغير تلقائياً لتأكيد الطزاجة).
- **حاوية الصورة الحقيقية (Real Photo Viewport):**
  - صورة عريضة بنسبة 16:9 بجودة WebP مضغوطة وعالية التباين، مع وجود شارة صغيرة في الزاوية: `[ 📷 صورة مباشرة ]`.
  - إمكانية التمرير الأفقي في حال رفع المقاوتي أكثر من صورة واحدة.
- **معلومات الصنف والمقاوتي (Metadata):**
  - عنوان القطفة بخط عريض (مثال: *"همداني سوبر - قطفة الصباح حاز"*).
  - اسم المقاوتي: *"مفرش العم صالح"* بجواره شارة **الدرع الأخضر** `[ 🛡️ رقم موثق ]` ومتوسط النجوم `⭐ 4.9 (128 تقييم)`.
  - العنوان بالمعالم: `📍 سوق علي محسن - مفرش 14 بجوار بنك الكريمي`.
  - السعر البارز: بخط عريض ولون عقيقي مميز `15,000 ريال / حبة`.
- **شريط الإجراءات السريعة (Card Quick Actions):**
  - زر أخضر بارز عريض: `[ 💬 واتساب ]` بأيقونة الواتساب الرسمية؛ يفتح فوراً محادثة مع المقاوتي برسالة جاهزة.
  - زر ثانوي: `[ 📞 اتصال ]` بأيقونة الهاتف؛ يفتح شاشة الاتصال بالرقم الموثق.
  - زر المشاركة الذكية: `[ 🔗 ]` لمشاركة العرض بحالات الواتساب ومجموعات الأصدقاء.
  - زر المفضلة: قلب صغير لحفظ العرض.

### 3. شاشة خريطة أسواق القات ومواقع المفارش (Market Map & Stalls Screen)

#### الهدف من الشاشة:
تجسيد متطلب صاحب المشروع الجوهري: تمكين المشتري من رؤية خريطة أسواق القات في اليمن ومعرفة الموقع الدقيق لمفرش المقاوتي داخل السوق للتسوق المباشر.

```
┌──────────────────────────────────────────────┐
│ [←] خريطة سوق علي محسن - صنعاء      [🔍]    │
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │
│ │             خريطة تفاعلية خفيفة          │ │
│ │                 (OpenStreetMap)          │ │
│ │                                          │ │
│ │      [بوابة السوق الغربية]                │ │
│ │         │                                │ │
│ │         ├── 🟢 [مفرش صالح]               │ │  <- دبوس متوفر الآن
│ │         │                                │ │
│ │         ├── ⚫ [مفرش ناصر - نفد]         │ │  <- دبوس نفدت الكمية
│ │         │                                │ │
│ │         └── 🟢 [مفرش الشامي]             │ │
│ │                                          │ │
│ │               [📍 موقعك الحالي]          │ │
│ └──────────────────────────────────────────┘ │
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │
│ │ بطاقة المفرش المحدد:                      │ │
│ │ 🏪 مفرش العم صالح (رقم 14)  🛡️ رقم موثق  │ │
│ │ 🌿 قطفة شامي متوفرة الآن  💰 12,000 ريال │ │
│ │ [ 💬 مراسلة واتساب ]   [ 📞 اتصال فوري ] │ │
│ └──────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

#### تفصيل المكونات:
1. **الشريط العلوي للخريطة:**
   - زر الرجوع السريع `[←]`.
   - اسم السوق الحالي والمحافظة: *"سوق علي محسن - صنعاء"* مع زر تغيير السوق.
   - زر التكبير/التصغير وأيقونة `[🎯 حدد موقعي الآن]`.
2. **محرك الخريطة الخفيف (Map Engine):**
   - خريطة تفاعلية سريعة تعمل بمحرك FlutterMap وبلاطات OpenStreetMap المخزنة مؤقتاً في الذاكرة لتوفير استهلاك باقات النت.
   - حدود السوق الشعبي محددة بلون أخضر خفيف شفاف.
3. **دبابيس المفارش التفاعلية (Stall Pins):**
   - **الدبوس الأخضر النضر:** يشير إلى مقاوتي لديه قطفة حية متوفرة الآن في السوق.
   - **الدبوس الرمادي:** يشير إلى مفرش مغلق أو نفدت بضاعته لليوم لمنع المشي غير المجدي.
   - **الدبوس الذهبي المميز:** لمقاوتي مشترك في باقة التوثيق الذهبية.
4. **بطاقة المفرش المنبثقة السفلية (Bottom Stall Peek Card):**
   - عند النقر على أي دبوس، تنبثق بطاقة سفلية أنيقة تعرض اسم المقاوتي، رقم مفرشه، صورة حية لقطفة اليوم، وسعرها، مع زري الاتصال والواتساب الفوريين، وزر `[ افتح في خرائط Google للاتجاهات ]`.

### 4. شاشة تفاصيل القطفة وتكبير الصور الحقيقية (Drop Details Screen)

#### الهدف من الشاشة:
فحص القات بدقة متناهية، والتأكد من جودة الورقة ونضارتها، ومعرفة وقت ومزرعة القطف، ثم إجراء الطلب المباشر.

```
┌──────────────────────────────────────────────┐
│ [←] تفاصيل القطفة             [🚩] [❤️] [🔗] │
├──────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │
│ │                                          │ │
│ │      معرض الصور الحقيقية المكبرة         │ │  <- ميزة التكبير بالإصبعين
│ │             (1 / 3 صور)                  │ │
│ │                                          │ │
│ └──────────────────────────────────────────┘ │
│                                              │
│ 🟢 متوفر الآن           ⏱️ تم التحديث: منذ 12 د │
│ همداني سوبر فاخر - قطفة الصباح               │
│ 💰 14,000 ريال يمني / حبة                    │
│                                              │

│ • الوحدة: حبة مشدودة ممتازة                  │
│                                              │
│ ── بيانات التاجر والمفرش ────────────────── │
```

#### تفصيل المكونات:
1. **معرض الصور التفاعلي (Interactive Media Carousel):**
   - صور كاملة العرض مع دعم الإيماءات (Pinch-to-Zoom) لتكبير ورقة القات وفحص نضارتها ومصداقية الصورة.
   - عداد الصور السفلي النقاطي `(1 / 3)`.
2. **أزرار الشريط العلوي التفاعلية:**
   - زر الرجوع `[←]`.
   - زر الإبلاغ عن عرض مضلل `[🚩]`.
   - زر المفضلة `[❤️]`.
   - زر المشاركة بالروابط الذكية `[🔗]`.
3. **صندوق المواصفات الزراعية والتجارية:**
   - جدول بطاقات صغيرة يوضح: منطقة المزرعة، ساعة القطف، الجودة، ونوع العملة المتداولة (طبعة قديمة بصنعاء أو جديدة بعدن لتفادي أي التباس).
4. **بطاقة المتجر المدمجة:**
   - تنقل المشتري بضغطة واحدة إلى الملف الكامل للتاجر أو إلى مكانه على خريطة السوق.
5. **شريط الإجراءات الثابت السفلي (Persistent Bottom CTA):**
   - شريط بارز مثبت أسفل الشاشة بارتفاع 65dp، يتضمن زر الواتساب باللون الأخضر العريض وزر الاتصال الهاتفي باللون البرتقالي العقيقي، متاحان بنقرة إبهام واحدة.

### 5. نافذة النشر الخاطف للقطفة للمقاوتي في 30 ثانية (Seller Quick Drop Publisher)

#### الهدف من الشاشة:
تطبيق مبدأ صاحب المشروع الحاسم: **"فائدة واضحة للمقاوتي دون أي عبء على عمله"**. نافذة منبثقة سريعة تفتح بنقرة واحدة، ولا تتطلب كتابة أي نصوص، وتُنجز النشر في 25-30 ثانية فقط!

```
┌──────────────────────────────────────────────┐
│  [×] نشر قطفة اليوم الطازجة (أقل من 30 ثانية)│
├──────────────────────────────────────────────┤
│ 1. صورة القات الحية:                         │
│ ┌──────────────────────────────────────────┐ │
│ │    [ 📷 افتح الكاميرا والتقط الصورة ]     │ │  <- تشغيل الكاميرا بنقرة واحدة
│ └──────────────────────────────────────────┘ │
│                                              │
│ 2. اختر نوع القات:                           │
│ ( شامي ) ( همداني ) ( قعطبي ) ( عنسي )       │  <- رقاقات ضخمة بإبهام واحد
│ ( رداعي ) ( أرحبي ) ( غيلي ) ( صعدي )        │
│                                              │
│ 3. السعر بالريال:                            │
│ ┌────────────────────────┐  الوحدة:          │
│ │ 15000                  │  [ حبة ▼ ]        │  <- لوحة أرقام ضخمة وسهلة
│ └────────────────────────┘                   │
│                                              │
│ 4. حالة التوفر الحالية:                      │
│ [ 🟢 متوفر في مفرشي الآن ]  [ 🔴 نفد ]       │
├──────────────────────────────────────────────┤
│    [ 🚀 انشر القطفة فوراً لزبائن السوق ]     │  <- زر أخضر عريض بملء العرض
└──────────────────────────────────────────────┘
```

#### تفصيل عناصر الواجهة الخاطفة:
1. **مربع التقاط الصورة الفوري (Live Camera Viewport):**
   - زر كبير ومباشر يشغل كاميرا الهاتف الخلفية فوراً؛ يلتقط التاجر صورة حزم القات المعروضة في مفرشه بنقرة واحدة وتظهر المعاينة فوراً مع إمكانية إعادة الالتقاط بنقرة.
2. **شريط رقاقات الأصناف بنقرة إبهام (Single-Tap Qat Chips):**
   - أزرار دائرية مريحة لاختيار نوع القات دون الحاجة لفتح قوائم معقدة أو كتابة أي حرف على الكيبورد.
3. **حقل السعر المخصص (Big Number Input):**
   - حقل إدخال رقمي كبير يستدعي تلقائياً لوحة مفاتيح الأرقام الكبيرة (Numeric Pad)، مع قائمة منسدلة سريعة للوحدة: `[حبة]` (افتراضي)، `[قبضة]`، `[كيس]`، `[كيلو]`.
4. **مفتاح التوفر الفوري (Availability Switch):**
   - محدد مسبقاً على خيار `[ متوفر الآن 🟢 ]`.
5. **زر النشر العملاق (Big Action Button):**
   - زر بارز أسفل النافذة: عند الضغط عليه، يتم ضغط الصورة فوراً على الجهاز وتحويلها إلى WebP بحجم أقل من 80KB، وإرسال البيانات للسيرفر في الخلفية، وإغلاق النافذة مع صوت اهتزاز نجاح لطيف (Haptic Success Feedback).

   - يولد بلمسة واحدة بطاقة دعائية مصورة للقطفة مع رابطها الذكي لمشاركتها مباشرة في حالات الواتساب ومجموعات الأصدقاء.

## 4. إرشادات هندسة التباين والاستخدام تحت أشعة الشمس (High-Contrast & Outdoor Standards)

1. **نسبة التباين اللوني (Contrast Ratio):**
   - الالتزام بنسبة تباين لا تقل عن **7:1** للنصوص وعناصر الأسعار مقارنة بالخلفية (مطابقة لأعلى معايير WCAG AAA).
   - تجنب استخدام النصوص الرمادية الفاتحة على خلفيات بيضاء؛ فجميع النصوص الثانوية تعتمد اللون الرمادي الداكن المائل للأزرق (`#4A5568`).
2. **حجم مناطق اللمس (Touch Targets):**
   - لا يقل أصغر زر تفاعلي في واجهات التطبيق عن **48dp × 48dp** لتسهيل الضغط السريع حتى بأصابع الأيدي المبللة أو المشغولة في السوق.
3. **لوحة المفاتيح الرقمية المتخصصة:**
   - عند إدخال الأسعار، تظهر أزرار أرقام عملاقة (ارتفاع الزر 60dp) لتفادي أخطاء الإدخال أثناء الوقوف والحركة في السوق.
