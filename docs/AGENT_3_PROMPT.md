### نص التكليف الموجه للوكيل الثالث (انسخ هذا النص كاملاً إلى نافذة المحادثة الخاصة بالوكيل الثالث):

```markdown
مرحباً بك! أنت الوكيل الثالث (Agent 3) في فريق تطوير تطبيق Flutter لمنصة «قطفة (Qatfa)» - أكبر سوق إلكتروني للقات في الجمهورية اليمنية.

### 1. سياق العمل والفرع المنفصل الإلزامي:
- **تحذير هام:** أنت مكلف بالعمل على **فرع منفصل تماماً** وعدم التعديل على `main`.
- أول خطوة تقوم بها في الطرفية فور استلام المهمة:
  ```bash
  git pull origin main
  git checkout -b feature/seller-flow-and-profile
  ```
- تم بالفعل تشييد **البنية التحتية لتصميم الواجهات (Design System)** في مجلد `apps/mobile/lib/core/`:
  - `lib/core/theme/`: الألوان الفاتحة والداكنة (`app_colors.dart`), سلم خط القاهرة العربي (`app_typography.dart`), المسافات والشبكة (`app_spacing.dart`), والظلال والتوهج (`app_shadows.dart`), و `app_theme.dart`.
  - `lib/core/responsive/`: كاشف الشاشات (`screen_breakpoints.dart`), والتخطيط التكيفي (`responsive_layout.dart`), وويدجت تطويق وحماية مقاسات الخطوط (`text_scaler_boundary.dart`).
  - `lib/core/widgets/`: الأزرار المجهزة (زر الواتساب التلقائي `QatfaWhatsAppButton`, زر الاتصال `QatfaPhoneButton`, الزر الرئيسي `QatfaPrimaryButton`), الشارات `QatfaStatusBadge`, الرقاقات `QatfaChoiceChip`, حقل البحث البيضاوي `QatfaSearchField`, بطاقات الحجز `BookingCard`, بطاقة الإحصائيات `StatCounterCard`, وشريط التنقل السفلي المطور `QatfaBottomNavBar`.
- كافة المكونات خالية تماماً من الأخطاء والتحذيرات (`flutter analyze` سليم 100%).

### 4. المهام المكلف بإنجازها بالتفصيل:

#### المهمة 1: واجهة النشر السريع للمقاوتي وتجهيز القوائم المسبقة (`QuickPublishFlow` & `Presets`):
- الموقع: `lib/ui/features/seller/views/quick_publish_screen.dart` و `seller_presets_screen.dart`.
- المبدأ الحاكم: **فائدة فورية بدون أي عبء إداري** (النشر في أقل من 30 ثانية و3 نقرات فقط لأن المقاوتي تكون يداه مشغولتين في فرز الحزم واستلام النقود).
- المكونات والمنطق:
  - كاميرا التقاط حية فورية ومضغوطة تلقائياً إلى صيغة WebP.
  - حقل إدخال رقمي كبير للسعر بنقرة واحدة مع لوحة أرقام مريحة.
  - اختيار الصنف والنوع من الرقاقات المجهزة مسبقاً (أنواع: عنسي، همداني، شامي... أصناف: رووس، عوارض، قطل...).
  - شاشة تجهيز القوائم المسبقة للمقاوتي (Presets) ليحدد ما يبيعه بانتظام بضغطة زر.
  - التحكم المزدوج بالتوفر:
    - مفتاح المتجر العام (Master Store Toggle) لفتح أو إغلاق استقبال الطلبات لمتجره ككل بنقرة واحدة.
    - مفتاح المنتج المستقل (Per-Product Toggle) لتغيير الحالة فورياً [متوفر / نفدت الكمية].

#### المهمة 2: شاشة الحجوزات والمتابعات (`BookingsScreen`):
- الموقع: `lib/ui/features/bookings/views/bookings_screen.dart`.
- المكونات (مطابقة تماماً للصورة 3 في `apps/mobile/images_ui/5778591430203871630_120.jpg`):
  - ترويسة الشاشة مع أيقونة لوحة الحجوزات والعنوان: *"حجوزاتي - كل حجوزاتك في مكان واحد"*.
  - شريط تبويبات الفئات بعدادات رقمية واضحة:
    - `[ 📋 الكل (3) ]`
    - `[ ⏱️ قيد التأكيد (1) ]`
    - `[ 🟢 مؤكد (1) ]`
    - `[ 🟢 مكتمل (1) ]`
  - قائمة بطاقات الحجوزات التفصيلية باستخدام `BookingCard`:
    - حالة قيد التأكيد: زر إلغاء الحجز وزر عرض التفاصيل.
    - حالة مؤكد: زر اتصال فوري بالمقاوتي وزر عرض التفاصيل.
    - حالة مكتمل: زر تقييم التجربة بنجوم خضراء.
  - بطاقة الملخص المالي والكمي الخضراء في الأسفل:
    *"إجمالي حجوزاتك: 3 حجوزات | بقيمة إجمالية: 42,000 ر.ي"* وشعار *"مع قطفة .. دائماً الأفضل"*.

#### المهمة 3: شاشة الملف الشخصي وإعدادات الحساب (`ProfileScreen`):
- الموقع: `lib/ui/features/profile/views/profile_screen.dart`.
- المكونات (مطابقة تماماً للصورة 1 في `apps/mobile/images_ui/5778591430203871628_120.jpg` مع مراعاة تصحيح عناصر الذكاء الاصطناعي):
  - رأس الحساب التراثي: خلفية الأخضر القاتمي المتدرج مع كبسولة الموقع وجرس التنبيهات.
  - بطاقة الملف الشخصي: صورة المستخدم داخل إطار دائري مزدوج مع شارة الكاميرا، الاسم، رقم الهاتف، شارة التوثيق `🛡️ مستخدم موثق`، وقائمة تبديل الصفة `[ مشتري ▼ / مقاوتي ]`.
  - شريط الإحصائيات الثلاثي باستخدام `StatCounterCard` (المكتملة، الحجوزات النشطة، المفضلة).
  - قائمة خيارات الحساب والصفوف التفاعلية بالأيقونات الملونة:
    1. **البيانات الشخصية** (أيقونة مستخدم)
    2. **الأسواق والمفارش المفضلة** (أيقونة موقع)
    3. **المفضلة** (أيقونة قلب)
    4. **سجل الطلبات والحجوزات** (أيقونة لوحة مهام)
    5. **الإشعارات** (أيقونة جرس مع نقطة تنبيه حمراء)
    6. **الإعدادات وتخصيص الاستخدام** (أيقونة ترس)
    7. **الدعم الفني والمساعدة** (أيقونة سماعة)
    8. **تسجيل الخروج** (حاوية حمراء فاتحة بنص وأيقونة خروج واضحة)
  - التذييل التراثي بمدرجات جبال اليمن مع العبارة الملهمة *"مع قطفة .. نزرع الخير ونحصده معاً"*.

### 5. قواعد العمل الإلزامية، نظام الـ Commits، والرفع النهائي:
1. **الالتزام بالـ Commits:** عند الانتهاء من كل شاشة أو تدفق، قم بعمل `git commit` فوري ومستقل برسالة واضحة بصيغة Conventional Commits، مثل:
   - `feat(mobile): implement QuickPublishFlow with live camera and presets`
   - `feat(mobile): implement BookingsScreen with status filters and summary card`
   - `feat(mobile): implement ProfileScreen with role switcher and heritage footer`
2. **التحقق المستمر:** بعد كل إنجاز، تحقق من:
   - تشغيل `flutter analyze` والتأكد من `No issues found!`.
   - تشغيل `flutter test` والتأكد من نجاح كافة الاختبارات.
3. **الرفع النهائي (Crucial Rule):**
   - عند اكتمال كافة مهامك بنجاح، قم برفع البرانش إلى GitHub:
     ```bash
     git push -u origin feature/seller-flow-and-profile
     ```
   - **لا تقم بدمج البرانش في `main` مطلقاً!** اتركه مرفوعاً كـ branch منفصل ليكون جاهزاً للمراجعة وإنشاء الـ Pull Request.
