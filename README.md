## 📌 نبذة عامة عن المشروع

**قطفة (Qatfa)** هي منصة رقمية اجتماعية وتجارية صُممت خصيصاً لإعادة هيكلة ورقمنة أضخم سوق استهلاكي وتجاري يومي في اليمن: **سوق القات**.

لا تقتصر المنصة على كونها دليلاً جغرافياً للمتاجر، بل هي **شبكة تجارة اجتماعية حية (Live Social-Commerce Ecosystem)** تمكّن تجار القات (المقاوتية) والمزارعين من بناء علاماتهم التجارية، ونشر عروضهم اليومية "القطفة الطازجة"، وبناء سمعة موثوقة قائمة على التقييمات الشفافة، وتتيح للمستهلكين استكشاف أفضل أنواع القات القريبة منهم، ومتابعة مقاوتيتهم المفضلين، والتواصل المباشر معهم لحظة وصول الشحنات اليومية عبر الاتصال ومحادثات WhatsApp.

## 🎯 الركائز الأساسية الحاكمة لتجربة منصة "قطفة"

```
        ┌─────────────────────────────────────────────────────────────┐
        │                 ركائز تجربة منصة قطفة                       │
        └──────────────────────────────┬──────────────────────────────┘
                                       │
         ┌───────────────┬─────────────┼───────────────┬──────────────┐
         ▼               ▼             ▼               ▼              ▼
┌─────────────────┐ ┌──────────┐ ┌───────────┐ ┌───────────────┐ ┌─────────────┐
│ بيع وخريطة السوق│ │إنهاء فوضى│ │عروض متجددة│ │ توثيق وأمان   │ │تسويق مستمر  │
│ وصور وأنواع القات│ │ المجموعات│ │متوفر / نفد │ │أرقام + بلاغات │ │ بروابط ذكية │
└─────────────────┘ └──────────┘ └───────────┘ └───────────────┘ └─────────────┘
```

1. **الأساس هو بيع واستكشاف القات:** عرض أصناف القات اليمني (همداني، شامي، قعطبي...)، وصوره الحقيقية، وتقييماته، وخريطة تفاعلية لأسواق القات في اليمن ومواقع مفارش المقاوتية.
2. **إنهاء فوضى مجموعات وقروبات الواتساب:** يستعرض المشتري كافة الصور والأسعار والمناطق وأسماء المقاوتية في منصة موحدة، ويتواصل مباشرة مع التاجر المناسب دون تشتت بين المجموعات.
3. **العروض المتجددة اللحظية:** صور حقيقية، أسعار محددة وشفافة، وقت التحديث بالدقائق ("تم التحديث قبل 10 دقائق")، وحالة فورية: [متوفر / نفد].
4. **ثقة المشتري وأمان التعامل:** توثيق أرقام هواتف البائعين عبر OTP مع شارة توثيق رسمية، وتوفير زر سريع للإبلاغ عن أي عروض مضللة.
5. **سهولة وسرعة فائقة:** فتح التطبيق فوراً (في أقل من 1.5 ثانية) واستهلاك خفيف جداً لباقات الإنترنت يناسب شبكات 3G اليمنية.
6. **فائدة واضحة للمقاوتي بدون عبء تشغيلي:** واجهة مصممة لإنجاز نشر القطفة في 30 ثانية لتجلب له زبائن ومبيعات جديدة دون أي عبء إداري على عمله.
7. **تسويق مستمر بروابط مباشرة (Deep Linking):** مشاركة بطاقات العروض على منصات التواصل (حالات واتساب، فيسبوك، تليجرام) برابط مباشر يفتح تفاصيل العرض فوراً داخل «قطفة».
